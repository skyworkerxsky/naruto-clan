# naruto-clan.net — озвучка 2x2

Chrome-расширение для [naruto-clan.net](https://naruto-clan.net). Автоматически выбирает озвучку **2x2** в Плеере 2, пропускает заставку и титры, включает следующую серию автоматически.

## Возможности

- Автовыбор озвучки 2x2
- Пропуск заставки и титров в Плеере 2
- Автопереход на следующую серию по окончании текущей
- Переключатели: расширение, озвучка, заставка, титры, автопереход — всё включено по умолчанию

## Установка

1. Открой `chrome://extensions`
2. Включи **Developer mode**
3. **Load unpacked** → выбери папку `naruto-clan-2x2-voice`

## Как пользоваться

Открой любую серию на naruto-clan.net, переключись на **Плеер 2** — озвучка 2x2 выберется сама, заставка пропустится.

Попап расширения (по клику на иконку):

- **Вкл/Выкл** — общий тумблер (бейдж `ON`/`OFF`)
- **Озвучка 2x2** — включить/выключить автовыбор
- **Пропустить заставку** / **Пропустить титры**
- **Следующая серия автоматически** — по окончании серии плеер сам переключится на следующую

## Проверка

1. Плеер 2 → в дропдауне выбрана озвучка **2x2**
2. «Следующая серия» → снова 2x2
3. Выключи расширение → озвучка больше не переключается
4. Досмотри серию до конца (или перемотай) → в плеере сама включается следующая серия
5. Console: `[2x2-voice:site]`, `[2x2-voice:player]`, `[2x2-voice:skip]`, `[2x2-voice:auto-next]`
