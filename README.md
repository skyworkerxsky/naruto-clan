# naruto-clan.net — озвучка 2x2

Chrome-расширение (MV3) для [naruto-clan.net](https://naruto-clan.net). На вкладке **Плеер 2** выбирает озвучку **2x2** вместо **Дублированный**.

## Попап

- Заголовок: `naruto-clan.net`
- **Вкл** / **Выкл** — общий выключатель. Зелёная кнопка значит расширение работает, красная — нет. Бейдж на иконке: `ON` / `OFF`.
- **Озвучка 2x2** — отдельный переключатель справа. Пока общий выключатель выключен, тогл тусклый, но его состояние сохраняется.
- **Пропустить заставку** — в Плеере 2 кликает «Пропустить заставку», когда кнопка появляется.

Все три включены по умолчанию.

## Как работает

1. `content/site.js` на странице серии, если оба выключателя включены: cookie `voice=2`, активная вкладка `#tab2`, в iframe `online-serial.com` параметр `translation=1`.
2. `content/player.js` внутри iframe кликает пункт **2x2** (`button.select__drop-item`, запасной `data-id="t1"`), если озвучка ещё не выбрана.
3. Если включён пропуск заставки, `content/skip-main.js` кликает `button.allplay__skip--intro`.
4. Выключение расширения или озвучки снимает `translation` с iframe. Выключение пропуска или всего расширения перестаёт кликать заставку.

## Установка

1. `chrome://extensions`
2. **Developer mode**
3. **Load unpacked** → папка `naruto-clan-2x2-voice`
4. Открой серию на naruto-clan.net

## Проверка

1. Вкладка **Плеер 2**, в дропдауне озвучки **2x2**
2. **Следующая серия** — снова 2x2
3. **Выкл** — плеер больше не переключается на 2x2
4. Console: `[2x2-voice:site]` / `[2x2-voice:player]`
